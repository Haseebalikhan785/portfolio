A high-performance, recruiter-optimized software engineering portfolio built with **React 19**, **TypeScript**, **Tailwind CSS**, and **Vite**, deployed to production cloud infrastructure on **AWS** with automated **Let's Encrypt SSL (HTTPS)**.

---

## ⚡ Key Highlights & Architecture

- **Sub-50ms Global Response Time:** Fully pre-compiled static bundle served via Nginx reverse proxy with gzip compression and aggressive asset caching.
- **15-Second Recruiter Scan Layout:** Structured according to the F-pattern hierarchy with key metrics, 9.17 / 10 CGPA distinction, tech stack badges, and 1-click verified resume download.
- **Bento Grid Architecture:** Modular, high-contrast dark/light mode UI styled with Tailwind CSS, featuring subtle micro-interactions, responsive navigation, and direct contact copy tools.
- **Production AWS Deployment:** Hosted on a dedicated AWS instance with a permanent Static IP (`15.252.41.119`), standard HTTP (Port 80), and automatic HTTPS SSL redirection (Port 443).

---

## 🛠️ Technical Stack

- **Frontend Core:** React 19, TypeScript 5.7, Vite 6
- **Styling & UI:** Tailwind CSS 3.4, PostCSS, Custom Zero-Dependency SVG Icon Suite
- **Hosting & Cloud:** AWS Lightsail (Ubuntu 24.04 LTS), AWS Static IP
- **Web Server:** Nginx 1.24.0, Let's Encrypt Certbot SSL
- **Typography:** Inter, JetBrains Mono

## 💻 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Haseebalikhan785/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Building for Production
```bash
npm run build
```
This generates the optimized production bundle in the `dist/` directory.
